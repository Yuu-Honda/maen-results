## 不確実性は十分だったか

![予測区間の被覆率](interval-coverage.png)

80%を目標に校正しましたが、未見細胞株で全6薬剤を同時に覆う率は55.6% / 44.4%でした。目標未達です。行単位では83.3% / 81.5%でしたが、細胞株全体への信頼性とは区別します。これは測定誤差や臨床安全性の区間ではありません。

## 何を計算したか

- NCI/DTP公式GI50集約値。既知抗がん剤6種×55細胞株＝330行。
- 学習37株/222行、校正9株/54行、未見評価9株/54行。細胞株全体で分離し、行ランダム分割は使いません。
- pGI50 = −log10(GI50 [M])。応答誤差の単位であり、治療の成功率ではありません。
- 薬剤ごとに最大実験数の集約条件を採用し、6薬剤共通株を使用。3株未満の前立腺群2株は除外。
- モデルと固定係数は変更せず、seedだけ比較。testによるモデル選択やハイパーパラメータ探索はしません。
- 保存済み約1.16MBの公式データを再利用し、追加ダウンロードなし。CPU1スレッド・低優先度、各計算1秒未満。実測経過秒は[集計JSON](summary.json)に保存。

## 出典と再現

[NCI/DCTD Data](https://dctd.cancer.gov/data-tools-biospecimens/data) の [Compound Inhibition Bulk Data Download](https://dtp.cancer.gov/dtpstandard/subsets/comp.jsp) を公式取得スクリプトで使用。[NCI再利用方針](https://www.cancer.gov/policies/copyright-reuse)は一般テキストについての方針で、データ固有の再配布権を確認したとは扱いません。生XML・細胞株別応答・予測表は公開対象に含めず、集計結果・方法・出典URL・checksumだけを載せています。

MAEN作業コピーで実験コードcommit `cd1040556093c032e768548510d3daecba3e2bd3` を使い、同じchecksumのキャッシュを保持して次を実行します。公開集計JSONには元コードSHA256と実測秒も含みます。

```bash
nice -n 15 python3 maen.py run --seed 20261004 --out runs/check
nice -n 15 python3 maen.py run --seed 20261005 --out runs/sensitivity
```

取得が必要な場合はREADMEの `experiment` コマンドを使用します。上限は6薬剤/12MB、計算60秒、1スレッド。コード本体は非公開です。公開閲覧者に完全な実行環境が提供されているとは主張しません。
