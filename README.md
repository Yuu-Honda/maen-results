## 検証条件と読み方

6薬剤×55株。8株を固定保留し、47開発株を学習31・校正8・評価8に細胞株単位で分割。20seedを事前固定し、同じ株は分割を跨がず、モデル・係数10は変更せず調整なし。保留評価は学習39・校正8・保留8株。前回5分割とコホートが異なるので合算しません。

GI50は50%増殖抑制濃度。pGI50=−log10(GI50[M])。MAEは絶対予測誤差の平均、RMSEは二乗誤差平均の平方根。臨床効果や死亡率ではありません。区間は校正株の全薬剤最大残差の有限標本補正80%分位点から計算。被覆率は観測結果であり分布自由保証はありません。重なる開発分割を独立試行として検定しません。

全seedの指標・由来・checksum・事前設定hashは[集計JSON](summary.json)、平易な説明と専門詳細は[index](index.html)。計測区間0.0319秒、CPU1スレッド、既存キャッシュのみ。CLI起動・描画・公開ビルドは計測外。有料計算・GPU・新規データ取得なし。

次は別PRで公式分子発現特徴のID整合・trainfit標準化/欠損補完/PCA・train内部CVのRidgeを計画。薬剤拡張、打ち切り、用量反応、時間、併用Bliss/Loewe/HSA、PK/PDはさらに後の段階で未実装。臨床治療予測はしません。
